# Bookify versi PHP

Versi mandiri ini menggantikan Next.js/Prisma dengan PHP 8.1+ dan SQLite. Buka `http://localhost/Bookify/versiPhp/index.php` (sesuaikan nama folder proyek bila berbeda). Database `storage/bookify.sqlite` dan data demo dibuat otomatis pada kunjungan pertama. Halaman bisa dibuka langsung sebagai berkas PHP, misalnya `admin/dashboard.php` dan `api/books.php`.

Login demo: `ADMIN001` / `admin123` dan `MBR001` / `member123`.

Pastikan ekstensi `pdo_sqlite` aktif di PHP Laragon. Tidak perlu menjalankan `npm`, `next dev`, atau membuka port 3000.
